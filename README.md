# Happy Cleaning website

A responsive, accessible marketing website for Happy Cleaning, serving South Jersey and the Philadelphia area. Built with semantic HTML, CSS, and lightweight vanilla JavaScript—no build step or package install required.

## Files

- `index.html` — complete single-page website, including responsive styles, service descriptions, customer-review excerpts, FAQ accordions, and quote form.
- `favicon.svg` — matching brand icon.
- `robots.txt` and `sitemap.xml` — basic search-engine discovery files for the canonical website domain.

## Run locally

Open `index.html` in a browser, or run any static web server from the repository root.

## Quote form

The form validates required fields and opens a pre-filled WhatsApp message to the business number published on the official website. It does not submit data to this repository or store form submissions. Visitors review the message and press Send themselves. Phone and email links are also available.

## Before launch

Confirm with Happy Cleaning that the phone/WhatsApp route, email, operating hours, service-area examples, licensing/insurance statement, and all testimonial excerpts are accurate and approved. Review the external image selections and replace them with approved company photos when available. Test the quote flow on mobile and desktop.

## Deploy

This is a static site and can be deployed from the repository root on Vercel, Netlify, or GitHub Pages. Publishing this repository does **not** automatically replace the current live website or connect the production domain; configure hosting and domain routing separately after approval.
