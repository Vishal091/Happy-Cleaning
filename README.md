# Happy Cleaning website

A fast, responsive, accessible marketing website for Happy Cleaning, serving South Jersey and the Philadelphia area. Built with semantic HTML, CSS, and lightweight vanilla JavaScript—no build step required.

## Run locally

Open `index.html` in a browser, or serve the repository with any static web server.

## Contact flow

The quote form validates the required fields and opens a prefilled WhatsApp message to the business number published on the official website. Email and phone contact routes are also available. Before launch, confirm the WhatsApp number, service area copy, claims, and current business hours with Happy Cleaning.

## Deploy

Can be deployed as a static site on GitHub Pages, Netlify, Vercel, or any static host. Set the deployment output/root to the repository root.
